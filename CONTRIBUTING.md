# Contributing

Code Imagination is currently in preview.

## Development

1. Install dependencies with `pnpm install`.
2. Run `pnpm run check` and `pnpm test`.
3. Build with `pnpm run build`.
4. Press `F5` in VS Code to launch an Extension Development Host.

Keep analyzer changes covered by a focused fixture or unit test. Avoid introducing network-dependent code analysis; the core visualization should remain local and deterministic.
