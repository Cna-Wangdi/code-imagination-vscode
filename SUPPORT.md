# Code Imagination support

## Report a problem or request a feature

Open an issue at:

https://github.com/Cna-Wangdi/code-imagination-vscode/issues

Include:

- your VS Code version;
- your Code Imagination version;
- the source language and framework;
- the behavior you expected;
- the behavior you observed;
- a minimal example when possible.

## Diagnostic logs

Run **Code Imagination: Show Diagnostic Logs** from the VS Code Command Palette and include the relevant error messages in your report.

Code Imagination does not include full source contents in its diagnostic output. Review logs before sharing them and remove any project names, file paths, or other details you do not want to disclose.

## Privacy

Source analysis runs locally in the VS Code extension host. Code Imagination does not upload source code, require an account, or call an AI service.
